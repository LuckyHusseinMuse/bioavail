# API mocks

Real responses from the Absorb API (generated by `backend/pipeline/make_mocks.py`). File names are `METHOD_path.json`. Request bodies are in that script. Live docs: `/docs` on the API.

Auth: send `Authorization: Bearer <token>`. Before Auth0 is set up, set `AUTH_DEV_SECRET` in backend/.env and mint a token with `python -m api.auth dev|your-name`.
